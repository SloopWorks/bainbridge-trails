# Bainbridge Trails app (KMP + Compose Multiplatform)

Modules: `composeApp` (shared UI, KMP library), `androidApp` (Android shell), `iosApp` (Xcode shell).

## Requirements
- JDK 17+ (Homebrew `openjdk@17` is fine). The iOS Xcode build phase resolves `JAVA_HOME` itself
  (`/usr/libexec/java_home`, then Homebrew paths) if it is unset.
- Android SDK; create `app/local.properties` with `sdk.dir=/path/to/Android/sdk` (gitignored) or set `ANDROID_HOME`.
- Xcode (iOS 16+ deployment target).

## Map data (required before building)
The map renders bundled PMTiles copied from `data/dist/` (gitignored, built by the pipeline):

    scripts/sync-app-assets.sh

This copies `trails.pmtiles`, `basemap.pmtiles`, `trails.json`, `terrain/contours.pmtiles`,
`terrain/hillshade.pmtiles` into `composeApp/src/commonMain/composeResources/files/` (gitignored).
Style templates live in `files/styles/*.json` (committed, generated by `scripts/build-map-styles.py`; see
`docs/spikes/map-render/styles.md`); `{{basemap}}`, `{{trails}}`, `{{contours}}`,
`{{hillshade}}` are replaced at runtime with local `pmtiles://file://` URLs. The app copies the tile sets
to its private files dir on first launch and whenever the bundled `trails.json` `version` changes.
Map library: maplibre-compose (see `docs/spikes/map-render/notes.md`).

## Build
Android:

    cd app && ./gradlew :androidApp:assembleDebug

iOS (simulator):

    xcodebuild -project app/iosApp/iosApp.xcodeproj -scheme iosApp -sdk iphonesimulator build

## Notes
- `iosApp.xcodeproj` is hand-maintained (no xcodegen/project.yml); edit it in Xcode.
  Other Linker Flags include the system libs MapLibre's Metal runtime needs (`-lc++ -lz`, Metal, CoreText, ...).
- iOS is simulator-only for now: no signing team/provisioning configured.
- Display name: Android `androidApp/src/main/res/values/strings.xml`; iOS `INFOPLIST_KEY_CFBundleDisplayName` build setting.
